#import data from an API into our React Application

the front-end UI we created with react is only part of the full web aplication, the other part is the API (implemented with express) and the databases (used by our API and implementd with SQLite). We can communicate with an API (one that we create ourselvs or a third-party API) using a built-in JavaScript function called fetch(). We also use a React tool called useEffect which allows us to interact with things outside our React application like an API.
